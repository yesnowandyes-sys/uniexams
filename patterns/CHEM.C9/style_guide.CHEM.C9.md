# ESAT Chemistry C9 Style Guide: Acids, Bases, and Salts

## Quantitative Complexity & Arithmetic
*   **Calculator-Free Design:** All calculations involving moles, volumes, and concentrations are designed to be solved mentally or with minimal scratchpad working.
*   **Multiples of 10 & 25:** Volumes are frequently set to 20 cm³, 25 cm³, or 50 cm³ to allow for easy ratio calculations (e.g., `Q4`, `Q8`, `Q9`).
*   **Concentration Magnitudes:** Questions focus on 0.1, 1.0, and 10.0 mol dm⁻³ values to keep log10 (pH) calculations simple (pH 1, 7, 14).
*   **Stoichiometry over Equilibrium:** Quantitative questions prioritize stoichiometric neutralization (moles of H+ vs moles of OH-) rather than $K_a$ calculations. Weak acids are treated qualitatively or through the concept of 'strong vs weak' rather than partial dissociation math.

## Question Structure Patterns
1.  **The Comparative 'Test' Scenario:** A recurring format (e.g., `Q2`, `Q3`, `Q4`) lists 3 distinct tests (Rate, Neutralization Volume, Conductivity) applied to two systems (Strong vs Weak acid). The student must identify which specific tests yield different results.
2.  **The 'Which is Correct' List:** Questions present 3 numbered statements and ask for a combination (A-H) indicating which are true/correct. This tests multiple definitions or properties simultaneously.
3.  **Applied/Stoichiometry Context:** Some questions (`Q9`) embed the calculation in a real-world context (stach acid/antacids), requiring the student to parse a word problem to extract the initial moles of H+.

## Difficulty Calibration
*   **Easy:** Definition checks (Strong vs Weak indicators) and single-step stoichiometry (e.g., `Q8` pH of mixture).
*   **Medium:** Multi-property discrimination (e.g., `Q7` identifying visible changes) and Polyprotic logic (`Q5`).
*   **Hard:** Volumetric analysis with a twist (e.g., `Q9` calculating for a specific pH range rather than neutrality) and multi-step qualitative deduction (`Q6` identifying elements from reactions).

## Wording Conventions
*   **"Monoprotic":** Explicitly used to prevent ambiguity about the number of replaceable H+ ions.
*   **"Visible chemical change":** Used in qualitative analysis to distinguish precipitation/color change from neutralization.
*   **"Considered independently":** A crucial qualifier in comparative questions, preventing students from using data from Test 1 to interpret Test 2.
