## Step 1: Compute weighted frequencies

Write a script `scripts/compute_weightings.py` that reads the enriched corpus and outputs `data/weightings.json`.

For each corpus question (exclude source='generated' and is_out_of_spec=true):
- Parse the enrichment JSON to get: module_code, topic_code, difficulty_category (Easy/Medium/Hard)
- Parse the question ID to derive the source and its weight:
  - ESAT-* = 1.0
  - NSAA-*-S1-* = 0.95
  - ENGAA-*-S1-* = 0.85
  - TMUA-*-P1-* = 0.75
  - NSAA-*-S2-* = 0.75 if physics/chemistry, 0.50 if biology (derive from module)
- Accumulate weighted counts per (module, topic_code, difficulty_category)
- Also accumulate per (module, content_code) for sub-topic tracking
- Normalise to produce target proportions (sum to 1.0 within each module for topic distribution, and per module for difficulty distribution)

### Output format for weightings.json

```json
{
  "topic_weights": {
    "M1": {"M4": 0.15, "M5": 0.22},
    "P": {"P8": 0.10, "P9": 0.08}
  },
  "difficulty_weights": {
    "M1": {"Easy": 0.25, "Medium": 0.50, "Hard": 0.25},
    "P": {"Easy": 0.20, "Medium": 0.50, "Hard": 0.30}
  },
  "sub_topic_weights": {
    "M1": {"M4.17": 0.05, "M4.18": 0.03}
  }
}
```

## Step 2: Update coverage_tracker.py

Modify `scripts/coverage_tracker.py` to:
- Load weightings.json on init (fall back to current equal-weight if file missing)
- Use weighted topic distribution when picking the next cell to fill
- Track sub-topic coverage via content_code (from enrichment), not just topic_code
- Weight difficulty distribution per module using difficulty_weights (so a module with lots of hard corpus questions gets more hard generation targets)

## Important rules

- The 69 out-of-spec questions should be excluded from weighting computation
- If a topic in esat_taxonomy.json has zero corpus questions, give it a small default weight (e.g. 1/10th of the average) rather than zero — we still need to generate for spec-only topics
- The 20/50/30 Easy/Medium/Hard mix is a default fallback, but the actual corpus-weighted distribution should override it per module
